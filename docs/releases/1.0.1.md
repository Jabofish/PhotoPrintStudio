## 光影印坊 1.0.1

- **新版工作区**。左侧选纸张和版式，中央排版和裁剪，底栏管理照片与打印页，右侧集中修图、卡片装饰和输出。改进浅色模式、页码、素材栏、滑块以及按用途分组的快捷键。
- **可视化自定义排版**。支持网格生成、拖动照片框、磁吸、对齐和分布，也可按毫米输入位置与尺寸。可仅应用到当前页，或保存为模板。六寸二合一新增左对齐裁切版。
- **打印尺寸和预检**。修复打印份数输入与打印机切换。送印前检查驱动纸型和可打印区域，分开保存不同纸型、方向、DPI 和驱动设置的校准。爱普生 L8050 无边距精确打印可在驱动中选择「保持大小」，再用同一纸型核对测试卡。

仓库首页和使用手册已换成新版实拍截图。便携 ZIP 内也有图文手册，可直接打开 `使用手册.md`。

下载 Windows x64 ZIP，完整解压后运行 `PhotoPrintStudio.exe`。升级前先保存并退出旧版，再把 `portable_data` 复制到新版。ZIP 由 GitHub Actions 构建，附 SHA-256 与构建来源证明。
